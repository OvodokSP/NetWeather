# NetWeather Android 0.4.1 alpha preview

Это проверочная сборка Native Probe, а не стабильный production-релиз.

## Что входит

- локальные проверки доступности;
- история измерений;
- фоновые задачи и уведомления;
- виджеты;
- сохранение последнего состояния и выбранного интервала.

## Установка

- Android 10 или новее (`minSdk 29`);
- файл `NetWeather-0.4.1-alpha-debug.apk` подписан стандартным debug-ключом CI;
- перед установкой можно проверить SHA-256 по соседнему файлу
  `NetWeather-0.4.1-alpha-debug.apk.sha256`.

В этой сборке приложение получает обновляемый одноразовый код, который владелец подтверждает на сайте. После подтверждения приложение хранит отдельный device token и отправляет локальные результаты как `USER` probe. Код нельзя использовать как API-токен, а доступ устройства можно отозвать на сайте.

## Ограничения preview

- пакет имеет идентификатор `io.netweather.app.debug`;
- автоматическое обновление и production-подпись ещё не настроены;
- сборка проверена unit-тестами и CI-сборкой, но не подтверждена как стабильный релиз для
  повседневного использования на всех моделях устройств;
- приложение читает общий каталог и глобальную сводку из NetWeather API;
- после pairing приложение защищённо отправляет только результаты ресурсов, синхронизированных с сервером; это покрыто Android/backend CI-контрактами, но ещё не проверено на физическом Galaxy S25;
- production signing key и Play/App Gallery distribution пока не настроены.

Исходный код, история изменений и актуальный статус находятся в репозитории NetWeather.
